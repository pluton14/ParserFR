# 📊 Читалка статистики JSON

## Что это?

Это инструмент для красивого просмотра сохраненных JSON файлов статистики в удобном графическом интерфейсе.

## Как использовать?

### 1. Открыть читалку статистики

В главном окне программы нажмите кнопку **"📊 Открыть статистику"**

![Кнопка открыть статистику](docs/button.png)

### 2. Выбрать JSON файл

В открывшемся окне нажмите **"Открыть JSON файл"** и выберите нужный файл из папки `statistics/`

### 3. Просмотр данных

После загрузки файла вы увидите:

#### 📋 Информация о файле
- **Дата создания** — когда был создан файл статистики
- **Период поиска** — за какой период были собраны данные
- **Всего обработано статей** — общее количество проанализированных статей
- **Количество ключевых слов** — сколько слов/фраз искалось

#### 📊 Основная статистика (для каждого ключевого слова)
- **Найдено в X из Y статей (Z%)** — в скольких статьях нашлось искомое слово

#### 📝 Топ-20 слов слева
Таблица с самыми частыми словами, которые встречаются **слева** от искомого слова:
- **Слово** — само слово
- **Количество** — сколько раз встретилось
- **Процент** — процент от всех левых соседей

#### 📝 Топ-20 слов справа
Таблица с самыми частыми словами, которые встречаются **справа** от искомого слова:
- **Слово** — само слово
- **Количество** — сколько раз встретилось
- **Процент** — процент от всех правых соседей

### 4. Навигация между ключевыми словами

Если в файле статистики есть несколько ключевых слов, используйте кнопки:
- **◄ Предыдущее** — переход к предыдущему слову
- **Следующее ►** — переход к следующему слову

Текущее слово и его номер отображаются в центре: **"Слово: example (1/5)"**

## Преимущества читалки

✅ **Удобная навигация** — легко переключаться между ключевыми словами  
✅ **Таблицы** — данные о контексте представлены в наглядной табличной форме  
✅ **Сортировка** — слова отсортированы по частотности (самые частые сверху)  
✅ **Проценты** — легко понять, насколько часто встречается каждое слово  
✅ **Прокрутка** — можно просматривать длинные списки слов  
✅ **Обратная совместимость** — работает и со старыми JSON файлами

## Формат JSON файлов

Читалка работает с JSON файлами следующего формата:

```json
{
  "timestamp": "2025-01-20 14:30:00",
  "search_period": {
    "start_date": "2024-01-01",
    "end_date": "2024-01-31"
  },
  "total_processed_articles": 3000,
  "keywords": ["example", "test"],
  "statistics": {
    "example": {
      "articles_with_word": 150,
      "total_processed_articles": 3000,
      "percentage": 5.0,
      "left_context_words": {
        "the": 45,
        "a": 30,
        ...
      },
      "right_context_words": {
        "is": 40,
        "was": 25,
        ...
      }
    }
  }
}
```

## Советы по использованию

💡 **Сравнение результатов** — открывайте несколько окон читалки одновременно для сравнения разных файлов статистики

💡 **Экспорт данных** — если нужно сделать дальнейший анализ, JSON файлы можно легко импортировать в Excel, Python или R

💡 **Архивирование** — храните старые файлы статистики для отслеживания изменений во времени

## Где хранятся файлы?

📁 **Статистика**: `statistics/statistics_YYYYMMDD_HHMMSS.json`  
📁 **Примеры**: `examples/examples_YYYYMMDD_HHMMSS.html`

## Проблемы?

Если файл не открывается:
1. Проверьте, что это JSON файл из папки `statistics/`
2. Убедитесь, что файл не поврежден (откройте его в текстовом редакторе)
3. Файлы старого формата могут отображаться не полностью, но должны открываться без ошибок
